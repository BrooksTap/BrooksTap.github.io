Política de Privacidade - AutoVideos

Última atualização: 9 de novembro de 2026

O que é o AutoVideos

O AutoVideos é uma ferramenta pessoal, usada apenas pelo dono do canal do YouTube "O Poder do Sim", para enviar os próprios vídeos às próprias contas: canal do YouTube, Página do Facebook, Instagram @opoderdosim.oficial e conta do TikTok.

Dados acessados

Com a autorização do usuário (Google OAuth), a ferramenta usa a YouTube Data API para:

  • enviar vídeos para o canal do usuário (permissão youtube.upload);
  • ler o nome e as informações básicas do canal, para confirmar em qual canal está publicando (permissão youtube.readonly);
  • alterar a visibilidade (privado/público) dos vídeos que a própria ferramenta enviou (permissão youtube.force-ssl).

Com a autorização do usuário (Login do Facebook), a ferramenta usa a Graph API da Meta para publicar Reels na Página do Facebook e na conta do Instagram do próprio usuário e ler as estatísticas dessas publicações.

Com a autorização do usuário (Login Kit do TikTok), a ferramenta usa a Content Posting API do TikTok para publicar vídeos na conta do próprio usuário e ler as informações básicas do perfil (permissões user.info.basic, video.upload e video.publish).

Como os dados são guardados

O token de acesso fica salvo apenas no computador do próprio usuário. Nenhum dado é enviado para servidores do AutoVideos, porque não existe servidor: tudo roda localmente.

Compartilhamento

Nenhum dado é vendido, compartilhado ou usado para publicidade. O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. A ferramenta também segue os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Como remover o acesso

O usuário pode remover o acesso a qualquer momento em myaccount.google.com/permissions (Google), nas configurações de "Integrações comerciais" do Facebook e em "Configurações e privacidade → Segurança → Apps com permissão" no TikTok.
